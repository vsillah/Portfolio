## Exercise and model Operating File entry

**Prompt:** Use synthetic feedback from the same workflow. Record source ID, event, narrow proposal, evidence, privacy tier, approving human, owner, expiry, revocation path, and status. Reject one unsupported inference in writing. Then draft two controller rows: permitted preparation and a blocked external action. No live memory write or agent route is part of this exercise.

**Harbor example:** Source `SYN-FEEDBACK-01`: Morgan's invented correction to `SYN-BRIEF-01`. Event `SYN-EVENT-01`: staffing claim changed from “confirmed” to “available for review.” Proposal `SYN-PROP-01`: require a separate confirmation source before a draft may say “confirmed to teach”; tier classroom-only; owner Morgan; approver Morgan; review next fictional planning cycle; revocation by Morgan with a new dated event; status `pending`. Rejected proposal `SYN-PROP-02`: “Morgan dislikes all digital-skills sessions”—unsupported by source. There is **no approved memory** in this packet. Route A: compare a session option → evidence-comparison role → sample source IDs required → draft to Morgan. Route B: announce a session → no eligible agent → hold and hand to Morgan for a separate decision. Controller evidence records the rule and fallback, not a claim of actual execution.

**Claim map for source review:** Source → Event → Proposal → Memory, approval, ownership, and revocation derive from Chapter 6 and the workbook's “Source, Event, Proposal, Memory.” Intent, eligibility, assignment, evidence, and human fallback derive from Chapter 7 and “Controller Routing Policy.” The correction, rejected inference, and two routes are invented. “Open Brain” names an architecture in the source; no live memory service is demonstrated.
