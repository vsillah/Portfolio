## Exercise and model Operating File entry

**Prompt:** Produce a `Six-Beat Day` brief with brief, route, review, approve, recover, and learn. Each beat needs an item, evidence reference, owner, permissible next step, and stop condition. Include one failure and its version-preserving recovery path. End by answering, “What did I approve today that I should have questioned?” Use only invented activity; the preparation agent cannot grant its own authority.

**Harbor example — `SYN-DAY-01`:** Brief: paper Session Option Brief prepared from three invented source IDs; staffing hold `SYN-HOLD-01`, spend request `SYN-SPEND-01`, and research `SYN-RESEARCH-01` all open. Route: staffing to Morgan and the team; spend to a separate budget owner; research question to Morgan for protocol review. Review: one sample source is stale, so Morgan strikes an attendance claim and checks the trace reference. Approve: Morgan authorizes only a corrected paper draft for review; no session, spend, send, or research run. Recover: source-status field is missing from the handoff, so retain version A, request version B with the field, and record the reason; no automatic retry. Learn: propose a local rule that source status must appear on every brief, with Morgan as reviewer and expiry to be set. Closing question: “Did I mistake a clean draft for evidence that staffing was ready?” Answer: “I nearly did; the hold remains.” All times, counts, and events here are fictional classroom labels, not a live agent run.

**Claim map for source review:** The brief/route/review/approve/recover/learn rhythm, trace-aware review, human approval, recovery, and governed memory derive from Chapter 25. The worksheet's three-column brief and closing question derive from workbook “Six-Beat Day.” Harbor's Friday sequence and correction are fictional; no real operator action is asserted.
