## One continuous classroom case

The fictional **Harbor Learning Circle** is a made-up community workshop team. Each Friday, it considers whether to add one free digital-skills session the following month. A preparation agent may compare three invented, explicitly cleared sample inputs and draft a one-page **Session Option Brief**. The program lead, Morgan, decides whether to propose a session to the team. Nothing is booked, announced, sent, purchased, or added to a real calendar in these lessons. All names, dates, counts, IDs, and source excerpts in the examples are invented classroom data. The “agent” is a role in a paper design, not a running system.

The example advances in order: L01 defines the job and receipt; L02 names Morgan's decision; L03 makes a readable trace and source policy; L04 processes feedback as a memory proposal and routes the next request. Learners may substitute their own *workflow type* while using invented examples. Never request raw private records, credentials, real customer details, or live traces.

## Review and production boundary

Every crosswalk visual is a **review candidate only**. Do not place the registered A.M.I.N.A. plate, SAM artwork, first-receipt plate, book cover, or other lesson media into a slide or render without separate author, attribution, rights, privacy, and accessibility approval. The shot lists call for original neutral shapes and fictional text only if later authorized. This packet itself creates no assets.

Editor should read the complete narration aloud at the indicated pace; the time blocks include deliberate learner pauses. Source reviewer should compare each factual framework claim to the cited chapter and workbook section. Accessibility reviewer should check the proposed text, captions, focus order, and non-color cues once a prototype exists. Any change to a registered source requires a new hash binding through the Phase 1 process.
