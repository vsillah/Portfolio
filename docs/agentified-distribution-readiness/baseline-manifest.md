# Agentified distribution baseline

Audited 2026-11-20 at `f04390aadc25f018186ce1b4be85d711b719be52` (`origin/main`). The accompanying `manifest.json` is the machine-readable lesson inventory. This is a repository and static evidence audit, not a fresh authenticated production or browser qualification.

## Current substrate

- Sixteen lessons, eight content segments each, are defined in `lib/agentified-workshop-content.json` and rendered at `/agentified/learningplan`; `/agentified/operating-file` renders all sixteen exercises. Each lesson has a poster, one or two expandable diagrams, a read-along text view, a media source and caption track. `app/agentified/AgentifiedWorkshop.tsx` gates the illustrated media on exact source path, source hash, caption path, and duration agreement with `lib/agentified-source-media.ts`.
- All sixteen bound illustrated MP4s, source videos and VTTs exist and match their recorded SHA-256; all sixteen posters exist. The bound MP4s total 226,085,253 bytes (226.1 MB decimal). Recorded durations range from 237.687 to 600 seconds; per-lesson values and `ffprobe` container durations are in the JSON. L01's container duration is 0.226 seconds longer than its binding, a small timing discrepancy for the Phase 2 playback check. Presence and hash agreement establish file identity, not visual or audio quality.
- `lib/agentified-illustrated-bindings.json` records source, composite, caption and transcript hashes and a source approval commit. It also says `correctionReviewState: human_qa_pending`. `agentified/workshop/visual-review/packets.json` supplies script, source, rights and accessibility lineage for nineteen approved plate uses. The presentation audit under `agentified/workshop/presentation-illustration-audit/` sampled all sixteen final composites and reported defects in all 128 scene positions. Treat those findings as an issue inventory pending fresh contextual review, not proof that a proposed repair is approved.
- `lib/agentified-end-screens.ts` has hash-bound end-screen entries for L02–L16. L01 has no entry, so the current UI cannot show its contextual end-screen despite its bound video. Replay uses native controls; video position is stored by lesson, with a seek on metadata load. End-screen visibility follows playback time; lesson completion itself is a separate manual button. This split needs product review.
- Guest progress and answers use `localStorage` key `amadutown:agentified:guest-progress:v1`. Signed-in users explicitly claim guest work before account linkage. `app/api/agentified/member/route.ts` uses authenticated, version-scoped rows and revision checks in the existing accelerated member tables. The Operating File can be downloaded as Markdown. Account submission requires review and consent, and sends to human assessment; the UI states that no purchase or project is created. The page uses one MP4 source per lesson at all widths; no separate mobile source is selected. This audit made no database read or mutation.
- `app/api/agentified/member/credential/route.ts` supports a version-scoped completion credential, claim and verification-link management after all sixteen saved completions. The member dashboard has an Agentified credential component; the public verification route is `noindex`. The Agentified credential is more basic than Accelerated's downloadable certificate artwork.
- `/agentified` is a published book landing page with retailer links and a Learning Plan entry. The existence of a free entry link is not an entitlement or commercial packaging decision for the workshop. Confirm access, service conversion, support and distribution model separately.

## Evidence limits

The static inspection covered route code, tests, hashes, presence, sizes, source bindings and existing review receipts. It did not establish live production availability, authenticated persistence, cross-device recovery, 390×844 rendered quality, caption readability, presenter placement, analytics events, SEO indexing, CDN behavior, accessibility with assistive technology, or actual rights clearance beyond recorded source packets. Those are phase gates, not assumed passes.
