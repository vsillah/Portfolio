# Website company naming

Use **AmaduTown, LLC** for short authored website references and **AmaduTown Advisory Solutions, LLC** for the full company name. Uppercase display treatments may use **AMADUTOWN, LLC** or **AMADUTOWN ADVISORY SOLUTIONS, LLC**. Add the suffix once, with its comma; replace an existing unpunctuated LLC instead of appending another one.

This rule covers website pages, navigation/footer/contact/legal/auth/help copy, metadata/OG/JSON-LD, branded accessibility labels, authored admin labels, and company names in website-generated documents/previews. Reuse `lib/website-brand.ts` for shared display labels and the existing `COMPANY_DISPLAY_NAME` export for PDF branding where practical.

Keep Vambah Sillah's personal name unchanged. Preserve URLs, domains, email addresses, handles, filenames, assets/imports, technical keys, database entities and exact vendor/legal registration identifiers. Never normalize arbitrary customer or CMS content at render time. Operational agent prompts, workflow identities, outbound-only templates, historical authored content and source titles remain outside a website naming sweep. Report runtime/CMS and graphic-only references separately; changing them requires the appropriate source or design workflow.

When an accepted consent disclosure changes, advance its version. Retain prior disclosure evidence and its review artifacts; naming updates never rewrite consent history or confer sending permission.
