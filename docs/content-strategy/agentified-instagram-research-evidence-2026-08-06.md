## Amina refinement recommendations

### `AGT-IG-01`: Tease

Use a single image or very short Reel. The visual should make the tension visible before the caption has to explain it.

Recommended visual grammar:

- two-column contrast: "AI got faster" and "Trust did not";
- small receipt path below: source, boundary, gate, receipt;
- no platform screenshots unless separately cleared.

### `AGT-IG-02`: Teach

Use a saveable carousel. Each slide should explain one part of AMINA without overloading the reader.

Recommended slide rhythm:

1. AMINA is the operating loop around agentic work.
2. Align the job.
3. Map the source.
4. Instrument the receipt.
5. Negotiate the boundary.
6. Audit the result.
7. Save this before you give an agent more authority.

### `AGT-IG-03`: Proof

Use a proof carousel unless the approved video/B-roll workflow is ready. The strongest visual is a receipt checklist, not an abstract AI graphic.

Recommended proof elements:

- source packet;
- owner/role;
- boundary;
- human gate;
- receipt;
- signal after the work moves.

### `AGT-IG-04`: Offer

Use a short release Reel only if a rights-cleared visual asset and final public CTA are approved. Otherwise use a launch image plus companion carousel.

Recommended offer path:

- name the problem;
- name the operating principle;
- point to the release;
- avoid availability claims beyond the approved `/agentified` route.

## Facebook companion recommendation

Use Facebook as a Page companion channel after Instagram assets pass review. Do not treat it as the primary growth channel for this batch.

Recommended handling:

- Tease and offer can cross-post as image/Page posts.
- Teach and proof should use condensed Page captions that point back to the core idea rather than forcing a carousel-first Facebook experience.
- Facebook ads should wait until at least one organic Instagram/X/YouTube signal review is available or Vambah explicitly approves a learning-budget test.
