## Missing bindings and quote gate

Each batch JSON separates the **pre-job empty bindings** from **post-job required outputs**. Before a job: authorized provider account; approved avatar ID and rights receipt; approved avatar-native voice ID and rights receipt; privacy review receipt; binding all-in quote; provider billing units and rounding; enforceable credit or spend cap; and current exact batch authorization. The script and request hashes bind the input text already. The existing source manifests' “unbound recorded audio” stop rule remains preserved as a downstream composite gate; it is not a prerequisite to submit approved text to the provider. Obtain the account's current quote and cap evidence before requesting authority. A historical $0 incremental purchase does not imply a free job or available credits today. Keep the cap at $0 and execution disabled until the exact first job is separately approved and implemented through a new reviewed execution step.
