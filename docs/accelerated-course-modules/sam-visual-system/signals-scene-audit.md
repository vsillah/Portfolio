## Source and visual gate

- The full-map L01-03 still uses the exact 3300×2742 book raster as its orientation source. It is shown whole, with the three act labels repeated in the separate teaching line for mobile legibility.
- L02-02 and L05-01 use the new high-resolution Signals-column raster recreation. L05-03 uses the funnel-component raster recreation. The generated art is reviewed against the book plate for raw inputs flowing into one funnel, crossed and clean speech bubbles, ledger, people, funnel outlet, beacon, and separate target.
- The earlier standalone `sam-signals-plate.webp` and any crop-based or scaled Signals focus treatment are superseded for these four proposed scenes. Existing assets remain in place as historical source and are not rebound by this still-only package.
- If a later visual comparison finds an altered label, connector endpoint, funnel order, target relationship, or unreadable 390 px state, stop before video rendering.
